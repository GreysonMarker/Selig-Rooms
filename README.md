# Selig Rooms

First-person school horror game.

Play: https://after-hours-greyson.greysonmarker233.chatgpt.site

Controls: WASD or arrow keys to move, mouse to look, E to interact, hold Shift to sprint, Esc to pause.

The full game includes server-backed multiplayer lobbies. GitHub Pages alone cannot run the lobby API; the play link above includes the server.
