# Selig Rooms

First-person school horror game.

## Play

Open the deployment listed under this repository’s **Deployments → github-pages** section.

The standalone GitHub Pages edition runs single-player directly in your browser, with no ChatGPT hosting or login. Published from the gh-pages branch.

Controls: WASD or arrow keys to move, mouse to look, E to interact, hold Shift to sprint, Esc to pause.

The main branch retains the full project and multiplayer server code. GitHub Pages cannot run the lobby API; multiplayer is not available in the Pages edition.
